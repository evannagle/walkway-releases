# Walkway desktop previews

Signed and notarized macOS preview downloads for Walkway.

## Install

Download the ZIP from [Releases](https://github.com/evannagle/walkway-releases/releases), extract it, and move Walkway.app to Applications. These previews support Apple silicon Macs.

## Updates

Signed builds include a preview update feed. Choose **Walkway → Check for Update**. Walkway offers to restart once active work and drafts are clear.

Older unsigned previews require a manual installation of a signed version first.

These are early previews, not a stable release. Keep backups of important work. This repository contains release downloads, checksums, and update metadata. The packaged app includes editable runtime code and its required dependencies.
